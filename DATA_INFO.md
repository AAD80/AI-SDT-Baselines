# Data Directory

This folder is intended to hold the datasets used in the experiments. 
Due to their large size, the datasets are NOT included in this repository.

Please download the datasets from their official sources and place them in this folder:

1. **SDN Dataset (ITU-ML5G-PS-006):**
   - Download from: [Zenodo](https://zenodo.org/records/15303565)
   - Rename the downloaded file to: `test_data.csv`
   
2. **IIoT Dataset (X-IIoTID):**
   - Download from: [Kaggle](https://www.kaggle.com/datasets/munaalhawawreh/xiiotid-iiot-intrusion-dataset)
   - Rename the downloaded file to: `X-IIoTID dataset.csv`

Once placed here, you can run the scripts in the `../scripts/` folder.
